# Computação em Nuvem - CloudSim

Projeto desenvolvido para a atividade prática da disciplina de **Modelos de Implantação em Computação em Nuvem**.

## Objetivo

O objetivo deste projeto é realizar uma simulação de um ambiente de computação em nuvem utilizando o **CloudSim**, permitindo compreender conceitos relacionados à criação de datacenters, máquinas virtuais, brokers e execução de tarefas (Cloudlets).

## Tecnologias utilizadas

- Java
- Apache NetBeans
- Apache Maven
- CloudSim 7.0.1
- Git e GitHub

## Estrutura do projeto

O projeto utiliza Maven para gerenciamento das dependências.

O principal exemplo utilizado na atividade está localizado em:

`src/main/java/CloudSimExample1.java`

O arquivo:

`pom.xml`

contém as configurações e dependências necessárias para execução do CloudSim.

## Simulação

A simulação realizada utiliza:

- 1 Datacenter
- 1 Broker
- 1 Máquina Virtual (VM)
- 1 Cloudlet

Após a execução, o CloudSim apresentou o Cloudlet com status:

`SUCCESS`

e a compilação foi concluída com:

`BUILD SUCCESS`

## Execução

O projeto pode ser aberto e executado utilizando o **Apache NetBeans** com suporte ao Maven.

Após carregar as dependências do projeto, execute a classe:

`CloudSimExample1.java`
